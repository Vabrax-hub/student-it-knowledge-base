Podstawy systemu Git

Wprowadzenie

Git to rozproszony system kontroli wersji, który pozwala śledzić zmiany w kodzie źródłowym oraz współpracować w zespole.

Tabela poleceń Git

Polecenie Opis działania
git clone [url] Klonuje zdalne repozytorium na lokalny komputer.
git status Pokazuje stan drzewa roboczego i pliki oczekujące na zatwierdzenie.
git branch Wyświetla listę gałęzi w repozytorium lub tworzy nową.
git switch [nazwa] Przełącza bieżącą gałąź roboczą na wskazaną.
git add [plik] Dodaje zmiany do obszaru przygotowawczego (staging area).
git commit -m "komentarz" Tworzy commit zatwierdzający zmiany w historii.
git fetch Pobiera metadane i zmiany ze zdalnego repozytorium bez ich scalania.
git pull Pobiera i scala zmiany ze zdalnego repozytorium do bieżącej gałęzi.
git push origin [branch] Wysyła lokalne commity na zdalny serwer.
git log --oneline Wyświetla skróconą historię commitów w repozytorium.
