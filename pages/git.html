Przydatne polecenia

Oto najczęściej używane komendy w codziennej pracy z repozytorium:

Polecenie Opis działania
git status Pokazuje stan drzewa roboczego i śledzone pliki.
git add . Dodaje zmiany do obszaru przygotowawczego (staging area).
git commit -m "komentarz" Tworzy nowy commit z zatwierdzonymi zmianami.
