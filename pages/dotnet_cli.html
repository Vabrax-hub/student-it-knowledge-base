Tabela poleceń .NET

Polecenie Opis działania
dotnet --version Wyświetla zainstalowaną wersję zestawu .NET SDK.
dotnet --list-sdks Pokazuje listę wszystkich zainstalowanych na komputerze wersji SDK.
dotnet new list Wyświetla dostępne szablony projektów, które można utworzyć.
dotnet new console Tworzy nowy projekt aplikacji konsolowej.
dotnet restore Przywraca zależności i pakiety zdefiniowane w projekcie.
dotnet build Kompiluje kod źródłowy aplikacji do postaci pliku wykonywalnego.
dotnet run Kompiluje i uruchamia aplikację w konsoli.
dotnet clean Czyści katalog wyjściowy projektu (usuwa pliki po kompilacji).
