Interfejs wiersza poleceń .NET (.NET CLI)

Zarządzanie projektami C#

Podstawowe komendy do tworzenia, budowania i uruchamiania aplikacji konsolowych:

Polecenie Opis działania
dotnet new console Tworzy nowy projekt aplikacji konsolowej w bieżącym katalogu.
dotnet build Kompiluje projekt i sprawdza występowanie błędów.
dotnet run Kompiluje i uruchamia aplikację w konsoli.
